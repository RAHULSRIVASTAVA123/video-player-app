#  Video Player App

A modern, custom-built video streaming web app inspired by platforms like YouTube and Netflix.  
Built using **React + TypeScript**, with advanced playback controls, autoplay logic, mini-player mode, and a clean UI.

---

##  Features

###  Video Playback
- Custom HTML5 video player
- Play / Pause with keyboard (`Space`)
- Skip forward / backward **10 seconds**
- Mute / Unmute (`M`)
- Fullscreen support
- Smooth seek bar

###  Autoplay & Countdown
- Toggle **Autoplay ON / OFF**
- Automatic play of the **next video**
- Countdown displayed **only in the last 5 seconds**
- Safe cleanup (no memory leaks / negative countdowns)

###  Mini Player Mode
- Minimize video to bottom-right corner
- Continue watching while browsing recommended videos
- Expand back to full player anytime

###  Keyboard Shortcuts
| Key | Action |
|---|---|
| Space | Play / Pause |
| ← | Rewind 10s |
| → | Forward 10s |
| M | Mute / Unmute |
| F | Fullscreen |

###  Browsing Experience
- Category tabs (Animation, Education, Travel, Music)
- Grid-based layout (no horizontal scrolling)
- Recommended videos section
- Smooth navigation between videos

###  UI / UX
- Dark theme
- Modern overlay controls
- Skip indicator animation (+10s / -10s)
- Responsive design
- Clean, minimal layout

---

##  Tech Stack

- **React**
- **TypeScript**
- **React Router**
- **HTML5 Video API**
- **CSS (custom styling, no UI library)**
